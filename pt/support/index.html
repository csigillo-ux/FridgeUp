Suporte

O FridgeUp! é feito por uma só pessoa. Se algo não funcionar, ou tiveres uma ideia para a app, escreve-me — leio todas as mensagens.

O leitor não reconhece o meu produto

As bases de dados de códigos de barras não cobrem tudo, sobretudo marcas locais ou de supermercado. Adiciona o produto manualmente e fotografa a data de validade — o resto funciona igual.

Não recebo notificações

Verifica se as notificações estão ativas para o FridgeUp! nas Definições do iOS e, na app, em Definições, confirma que «Ativar notificações» está ligado e que há uma hora definida.

Como restauro a minha compra Pro?

Abre o ecrã Pro na app e toca em «Restaurar compras». O Pro é uma compra única associada ao teu ID Apple, por isso também funciona nos teus outros dispositivos.

O iCloud não sincroniza (iOS)

A sincronização iCloud é gratuita para todos. Confirma que tens a sessão iniciada com o mesmo ID Apple nos dois dispositivos e que o iCloud Drive está ativo. Depois de adicionares um produto pode demorar um minuto.

Posso mover um produto entre listas?

Sim. Toca no produto, escolhe Frigorífico, Congelador ou Despensa em «Mover para» e guarda. As listas separadas são uma funcionalidade Pro.

Existe versão para Android?

Sim, o FridgeUp! está no Google Play. Se algo não funcionar no Android, escreve para fridgeup.android@gmail.com.

A leitura do código de barras funciona sem internet?

Em parte. Da primeira vez que lês um código novo, o FridgeUp! procura o nome do produto online. Depois fica a lembrar-se dele no teu telemóvel e reconhece o mesmo código mesmo sem ligação. Se o produto não for encontrado, escreve o nome uma vez e ele também fica guardado. No iOS, estes nomes sincronizam entre os teus dispositivos através do iCloud; no Android ficam no dispositivo.

Continuas com problemas?

Escreve para o endereço da tua versão (iOS ou Android), com o teu dispositivo, a versão do sistema e uma captura de ecrã, se tiveres. Ajuda-me a encontrar o problema mais depressa.
